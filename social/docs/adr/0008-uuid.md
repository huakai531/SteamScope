# ADR-0008: Internal user UUIDs

Status: accepted design; future-phase behavior remains planned.

## Context

External identity must not couple all platform keys.

## Decision

UUID user primary keys; derive actor from session, never caller body.

## Alternatives considered

SteamID as every primary key; legacy integer IDs.

## Consequences

No legacy account upgrade by ID; DTOs remain explicit.

## Revisit conditions

No planned reconsideration absent a concrete storage constraint.
