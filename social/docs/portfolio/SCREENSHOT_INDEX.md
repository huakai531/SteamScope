# Public screenshot index

Prepared 2026-10-24 from the independent public candidate. All images are 1440 × 900, device scale 1, 100% zoom. Images 1–8 show the actual frozen UI with **isolated synthetic data**; image 9 is an architecture diagram. The screenshot harness makes no live Steam request and does not use real account sessions.

The three game covers are original geometric SVGs included under the project MIT license. Game titles, people and messages are fictional demonstration content. These images do not establish real users, game ownership or live Steam results. Earlier commercial-art captures were not copied into this repository or its history.

The candidate images were manually inspected for secrets, identity fields, private text, local paths and external artwork. PNG metadata checks found no text/EXIF chunks. This is the preparation review authorized by the owner, not a claim that the owner personally rechecked each new pixel. Remote publication remains separately gated.
